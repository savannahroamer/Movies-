# Min filmlista

En enkel webbsida där du kan spara filmer du sett och ge dem ett betyg. Byggd med React, Vite och Bootstrap.

## Så kör du projektet

1. Installera [Node.js](https://nodejs.org/).
2. Ladda ner projektet och gå in i mappen:

3. Installera det som behövs:
   ```
   npm install
   ```
4. Starta projektet:
   ```
   npm run dev
   ```
5. Öppna `http://localhost:5173` i webbläsaren.
